02 / Technical Limits

Why Standard RAG Fails on Technical Manuals

  • The Table Context Collapse

    Blind splitting separates rows from parent headers. A row stating Torque: 65 N·m loses its identity when separated from the cylinder head section.

  • The Redundancy Problem

    Engineering documents repeat the word "torque" or "install" thousands of times. Dense vectors collapse these similar structures, returning the wrong component specs.

  • Precision and Bounding Boxes

    Vector databases treat 10.5 N·m and 10 N·m as semantically identical. Page-level image dumping causes LLMs to mix diagram contexts.

03 / Architecture

The MechRabot Processing Pipeline

1. Refiner Agent

Translates colloquial Arabic/slang $\rightarrow$ English engineering terms via DeepSeek (temp=0.2).

2. Multi-Vector Embed

Creates Dense + Sparse + ColBERT vector spaces inside a single BGE-M3 GPU run.

3. Qdrant Hybrid VDB

Parallel prefetch (dense/sparse) $\rightarrow$ RRF Fusion $\rightarrow$ ColBERT token late-interaction reranking.

4. Generative Agent

Reads top-10 chunks, extracts precise specs with clear citations. Supports reasoning via DeepSeek-R1.

04 / Bounding Box Ingestion

Spatial Bounding Box Image Grounding

  • Targeted Image Association

    Instead of linking an entire page of diagrams to all text blocks on a page, MechRabot calculates geometric center distances between blocks.

  • Euclidean Coordinate Math

    Computes coordinate bounding box distances directly from layout JSON outputs. If distance $\le$ threshold (600px), a picture is linked.

  • Unprecedented Cost Savings

    Eliminates the need for expensive per-chunk Vision-LLM API calls or page-dumping, completely resolving image-to-text hallucination.

05 / Data Pipeline

Hierarchical Table Ingestion & Context Linkage

  • Heading Tree Tracing

    Every chunk traces upwards through elements in the document tree to capture section headers and prepend them directly to the embedded content (e.g. ENGINE > CYLINDER HEAD > INSTALLATION).

  • Parent-Child Table Schema

    Tables are indexed both as detailed row-by-row chunks (precision spec matching) and complete table blocks (conceptual matching), mapped via parent_table_id.

  • Linked List Traversal

    Every chunk holds sequential hashes (previous_chunk_id, next_chunk_id) allowing future multi-turn reasoning to walk forwards or backwards in the document contextually.

06 / Vectors

The BGE-M3 Multi-Vector Ingestion Strategy

BGE-M3 is the only open-source embedding model that extracts three distinct representation vectors simultaneously in a single, high-performance inference pass:

  • 1. Dense Vectors (1024-dim)

    Captures semantic meanings and contextual mapping (concept matching, e.g. finding "cylinder block seal" under "gasket").

  • 2. Sparse Vectors (Lexical BM25)

    Guarantees precise token matches for exact numbers, specifications, part counts, and safety tolerances (no semantic approximations).

  • 3. ColBERT (Late-Interaction Tokens)

    Applies fine-grained token-level cross-matching, handling automotive model codes, abbreviations, and slang alignment.

Single Inference Advantage

Unlike naive setups that run 3 separate pipelines, MechRabot maps Dense, Sparse, and ColBERT features together with zero-latency overhead.

07 / Retrieval Math

The 3-Stage Qdrant Hybrid Retriever

Stage 1: Dual Prefetch

Runs two searches concurrently against Qdrant's vector collection:

  • Dense ANN (top-50)
  • Sparse BM25 (top-50)

Stage 2: RRF Rank Fusion

Merges prefetch ranks mathematically, dampening dominance with constant k=60:

RRF(d) = 1/(60+r_dense) + 1/(60+r_sparse)

Stage 3: ColBERT Late Interaction

Performs token-by-token matrix re-scoring on top 50 candidates, outputting top 10:

Score(q,d) = Σ max(E_q[i] · E_d[j])
