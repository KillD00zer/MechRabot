# MechRabot Web UI — Design Sketch (AnythingLLM-Inspired, Frontend-Only)

## Overview

Standalone single-file chat UI styled after AnythingLLM's dark theme.  
**Frontend folder only — zero changes to `app/` code.**  
No auth, no build step. All text in English.  
Tech: single `frontend/index.html` — vanilla JS + Tailwind CSS (CDN) + Plus Jakarta Sans font.

---

## API Contract (existing, unchanged)

| Method | Path | Request | Response |
|--------|------|---------|----------|
| POST | `/query_endpoint` | `{"query": "..."}` | `{"answer": "...", "sources": [{"linked_images": [...]}]}` |

The HTML calls the **existing deployed Modal endpoint**.  
A `API_BASE` variable at top of the `<script>` sets the base URL (default: `""` for same-origin, or full Modal URL for cross-origin).

- **Font**: Plus Jakarta Sans (Google Fonts CDN)
- **Headings**: `font-bold`, white
- **Body**: `font-normal`, white
- **Secondary**: `text-white/60`, `text-sm`

### Spacing & Layout
- No card/bubble backgrounds on messages — text floats on dark `#1b1b1e` chat area
- User messages: **2px solid white border** (AnythingLLM signature), `rounded-lg`
- Bot messages: plain text, no border, no background
- Thin `border-white/10` dividers between sections
- Max width container: `max-w-3xl`, centered
- Generous vertical padding on messages (`py-3`)

### Animations (AnythingLLM-style)
1. **Dot-falling loader** — 3 gray dots falling in sequence (not bouncing)
2. **Message enter** — `scale(0) → scale(1.1) → scale(1)`, 150ms
3. **Status idle** — blue dot subtle opacity pulse (3s cycle)
4. **Status working** — yellow spinner SVG rotating (1s cycle)
5. **Status done** — blue checkmark SVG stroke-draw (0.4s), auto-fades to idle after 1.5s

## Section Details

### 1. Header
- **"MechRabot"**: `text-[#46c8ff]`, `text-2xl`, `font-bold`
- **"Smart Spare Parts Assistant"**: `text-white/60`, `text-sm`
- Bottom border: `border-b border-white/10`

### 2. Status Indicator
Single line with animated dot + text label:

| State | Dot | Text | Duration |
|-------|-----|------|----------|
| Ready | Blue dot (`bg-[#46c8ff]`), opacity pulse 3s | "Ready" (`text-white/60`) | persistent |
| Working | Blue dot hidden, yellow SVG spinner | "Working..." (`text-[#fec84b]`) | until response |
| Done | Blue dot + blue checkmark SVG draw | "Done" (`text-[#46c8ff]`) | 1.5s → auto Ready |

### 3. Chat Area
- Bg: `#1b1b1e`, scrollable, `flex-1`
- **Empty state**: chat icon (white/20) + "Ask about any spare part" centered
- **User messages**: `border-2 border-white rounded-lg px-4 py-3`, max-w-[80%], right-aligned, no bg
- **Bot answers**: plain text, no border, no bg, max-w-[90%], left-aligned, `whitespace-pre-wrap`
- **Loading**: dot-falling CSS animation (AnythingLLM's exact keyframes: 3 dots, staggered delays)
- **Message enter**: `transform: scale(0) → scale(1.1) → scale(1)`, 150ms ease-out
- **RTL detection**: auto-detect Arabic vs English per message, apply `dir="rtl"` or `dir="ltr"`

### 4. Image Row
- `id="images-row-container"`, `class="hidden"` by default
- Top border: `border-t border-white/10`
- Label: "Retrieved Images" in `text-white/30`, `text-xs`
- Horizontal scroll (`overflow-x-auto`), `flex gap-3`
- Each `<img>`: `h-24`, `rounded-lg`, `border border-white/10`, `object-cover`, `bg-[#27282a]`
- `onerror` → remove broken image; if container empty → re-hide

### 5. Input Area
- `bg-[#27282a]`, `border border-[#525355]`, `rounded-lg`
- Multi-line `<textarea>`, 3-4 rows default, auto-expands to 160px max
- Placeholder: "Type your question..." in `text-[#57585a]`
- Max 2000 chars
- **Send button**: `bg-[#46c8ff]`, white text "Send", `font-semibold`
  - Hover: `opacity-80`
  - Disabled: `bg-[#27282a] text-white/30 cursor-not-allowed`
- Enter → send, Shift+Enter → newline

## JavaScript Behavior

```
1. Page load → status=Ready, focus textarea, show empty state
2. User types + Enter/Send →
   - Append user bubble (white border), clear input
   - Status → Working (yellow spinner)
   - Append dot-falling loader
   - fetch(POST API_BASE + "/query_endpoint", {body: JSON})
   - AbortController for cancellation
3. Success →
   - Remove loader
   - Append bot answer (plain text)
   - Check sources[].linked_images[] → render image row if any
   - Status → Done (checkmark, 1.5s) → Ready
4. Error →
   - Remove loader
   - Append "Connection failed. Please try again." in red
   - Status → Done → Ready
5. Double-send → abort previous fetch, start new
```

### Configurable API URL
```js
const API_BASE = "";
// Set to your Modal deployed URL, e.g.:
// const API_BASE = "https://your-app--mechrabot-query-endpoint.modal.run";
```

If `API_BASE` is empty string, calls use relative path (works when HTML is served from same Modal app).  
Otherwise, calls use full URL (works when opened locally or from static host).

## States & Edge Cases

| Scenario | Behavior |
|----------|----------|
| Empty input | Send does nothing |
| Very long answer | `whitespace-pre-wrap`, chat scrolls |
| Network error | "Connection failed" in red |
| API error | Show error detail from response |
| Rapid double-send | Abort prev, start new |
| No images in response | Image row stays hidden |
| Broken image URLs | `onerror` removes img, hides row if empty |
| Arabic text | Auto-applies `dir="rtl"` to bubble |
| English text | Default `dir="ltr"` |
